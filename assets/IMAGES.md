# OpenCV C# 강좌 예제 이미지 세트 (합성 영상 카탈로그)

> 이 카탈로그는 머신비전 강좌(studyMachineVision)의 이미지 세트를 그대로 가져온 것입니다. 이 저장소에는 그중 `assets/manifest.json` 에 있는 파일만 포함되어 있습니다 (체스보드 02~08 · npz · onnx 제외). 코드 예시는 Python 이지만 좌표 · 정답은 같습니다: `cv2.imread("images/x.png", cv2.IMREAD_GRAYSCALE)` → `Cv2.ImRead("images/x.png", ImreadModes.Grayscale)`.

> 이 문서는 `python tools/gen_images.py` 가 **자동 생성**합니다. 직접 고치지 말고 생성기를 고치세요.
> 모든 영상은 numpy + OpenCV 로 그린 **합성 영상**(저작권 문제 없음)이며, 고정 시드로 매번 같은 결과가 나옵니다.
> 정답(ground truth)은 생성 파라미터에서 계산되며 `assets/images_truth.json` 에 기계가 읽을 수 있는 형태로 들어 있습니다.
> 핵심 정답은 `python tools/check_images.py` 가 실제 OpenCV 파이프라인으로 검증합니다.

## 공통 규약

- 실행 시 작업 폴더에 `images/<이름>.png`, `data/<이름>` 으로 복사됩니다 (`assets/manifest.json`). 예: `cv2.imread("images/washers.png", cv2.IMREAD_GRAYSCALE)`
- 좌표는 픽셀 `(x, y)`, 원점 = 왼쪽 위, **픽셀 중심이 정수 좌표** (OpenCV 규약). 서브픽셀 정답은 소수점으로 표기.
- 각도: 특별한 말이 없으면 **화면 기준 반시계(CCW)가 +** (`cv2.getRotationMatrix2D(center, angle, 1)` 과 같은 방향).
  객체 로컬 좌표 (u, v) → 화면: `x = cx + u·cosθ + v·sinθ`, `y = cy − u·sinθ + v·cosθ`.
- 그레이 영상은 1채널 8bit, 컬러 영상은 **BGR** 3채널 8bit. 대부분 센서 잡음(샷 잡음 모델: 밝은 곳 σ≈1.5~1.8, 어두운 곳 σ≈0.8, 약한 공간 상관), 비네팅/조명 기울기, 약한 블러(σ≈0.6~0.9)가 들어 있어 실제 카메라 영상처럼 보입니다. (용량 12 MB 제한 때문에 잡음을 이 정도로 맞춤 — `NOISE_SCALE` 로 조절)
- "잡음 없는 이상적 값" 과 실제 측정값은 잡음/블러 때문에 약간 다를 수 있습니다 (허용 오차는 항목별 설명 참고).
- `images_truth.json` 은 저작/검증용이며 manifest 에 없어서 실행 환경에는 복사되지 않습니다. 수업 코드에서 정답이 필요하면 이 문서의 값을 코드에 직접 적으세요.
- 재생성: `python tools/gen_images.py` → 검증: `python tools/check_images.py`

- 파일 74개, 총 10.88 MB
